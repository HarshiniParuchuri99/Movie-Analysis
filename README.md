# Hollywood's Most Profitable Stories

## Project Overview
This project explores Hollywood movie profitability using exploratory data analysis (EDA). It examines profitability across movie genres and investigates the relationships between profitability, audience ratings, Rotten Tomatoes scores, and worldwide gross.

## Objectives
- Compare average profitability across genres.
- Identify movies with the highest profitability.
- Explore relationships between audience scores, critic ratings, profitability, and worldwide gross.
- Summarise findings using Python-based analysis and visualisations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib and Seaborn (if used in the notebook)
- Google Colab
- Jupyter Notebook

## Dataset
The dataset contains Hollywood movie information, including genre, lead studio, audience score, profitability, Rotten Tomatoes score, worldwide gross, and release year.

## Key Findings
- Drama movies had the highest average profitability in this dataset.
- *Fireproof* had the highest profitability value among the movies analysed.
- Audience scores and Rotten Tomatoes scores showed a positive relationship.
- Profitability had only a weak relationship with worldwide gross in this dataset.

## Project Files
- `hollywood-movie-profitability-analysis.ipynb` — notebook containing the analysis and visualisations.
- `hollywood_movies.csv` — dataset used for the analysis.

## How to Explore
Open the notebook on GitHub to review the code, analysis, and saved outputs. To rerun it, open the notebook in Google Colab and provide the CSV dataset when prompted.

## Conclusion
This project demonstrates exploratory data analysis, data interpretation, and visualisation skills using a movie dataset.
